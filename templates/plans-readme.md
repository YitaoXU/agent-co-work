# Plans and briefs

Keep project plans and long task Briefs here; short Briefs stay in their task records. Briefs follow [brief-template.md](brief-template.md).

Name a plan `NNN-<slug>.md` and its Brief `NNN-<slug>-brief.md`, sharing one three-digit number that is never reused, including work with only a Brief. Optional per-line subfolders each have their own README index; numbering is per folder unless the parent README declares it shared.

Next free number: 001

Keep each State cell to one short sentence: Ready, Running, Done with the headline, Closed, or Superseded. The coordinator updates it at named phase transitions and at Wrap-up/close. Execution detail stays in the task's State and `output/<yyyymmdd>/<task>/log.md`.
