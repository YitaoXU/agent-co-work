# Plans and briefs

This project or line-of-work folder holds plans and long task Briefs; short Briefs stay in their task records. Briefs follow [../brief-template.md](../brief-template.md).

Name a plan `NNN-<slug>.md` and its Brief `NNN-<slug>-brief.md`, sharing one three-digit number that is never reused, including work with only a Brief. Optional subfolders each have their own README index; numbering is per folder unless the parent README declares it shared.

Next free number: 001

Keep each State cell to one short sentence: Ready, Running, Done with the headline, Closed, or Superseded. The coordinator updates it at named phase transitions and at Wrap-up/close. Execution detail stays in the task's State and the Brief-named output log (default `output/<project>/<yyyymmdd>/<task>/log.md`, subject to the AGENTS.md layout).
