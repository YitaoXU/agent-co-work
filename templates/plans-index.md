# Plans and briefs

This index lists project or line-of-work folders. New plans and long Briefs go in `<project>/` (`_misc/` for project-less work); short Briefs stay in task records. Use [brief-template.md](brief-template.md). Each folder keeps its own README index and may contain subfolders; numbering is per folder unless the parent README declares it shared. Follow any existing layout declared in AGENTS.md; never move existing plans or change old citations.
